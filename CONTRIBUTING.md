# Contributing

Thanks for helping. Bug reports, encoder calibration results (especially VA-API and Quick Sync, which the
author can't test) and pull requests are all welcome.

## Building

Requirements: JDK 21, `ffmpeg`/`ffprobe` with an AV1 encoder, `avifenc`, and for the test fixtures
ImageMagick and `exiv2`.

```sh
./gradlew test spotlessCheck   # unit + integration tests, formatting
./gradlew test -Pgpu           # also the NVENC test (needs an NVIDIA GPU)
./gradlew spotlessApply        # fix formatting
./gradlew installDist          # build/install/backupthing/bin/backupthing
```

Integration tests run the real encoders on synthetic media generated by `scripts/gen-fixtures.sh`
(the `generateFixtures` task). **Never add real personal photos or videos to the repository.**

For manual testing, keep a config in `dev/config.toml` (gitignored) and run
`backupthing --config dev/config.toml serve`. Set `XDG_DATA_HOME` to a folder under `dev/` to keep the
test database separate from a real installation.

## Code layout

| Package | What it does |
|---|---|
| `config` | Settings model, validation, TOML store |
| `scan`, `classify` | Find new/changed media, decide photo / video / passthrough |
| `encode`, `probe`, `verify` | avifenc / ffmpeg wrappers and output checks |
| `upload` | `proton-drive` CLI wrappers; output parsing is isolated in `CliOutput` |
| `pipeline` | One backup run: state machine, retries, crash recovery |
| `scheduler`, `service` | `serve`: schedule, run lock, state for the UI |
| `web` | Ktor + htmx dashboard, settings, security |
| `safety` | `PathGuard`: the only code allowed to write or delete files |

Ground rules:

- Source files are only ever read. Anything that writes or deletes goes through `PathGuard`.
- External tools are run with argument lists, never through a shell.
- Every source file starts with `// SPDX-License-Identifier: GPL-3.0-or-later` (Spotless adds it).

## Pull requests
